# 解剖视角与标注规范

## 方向

左右按模型自身定义，而不是按观察者。依据是 [OpenStax 的解剖方位规范](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-6-anatomical-terminology)。本模型坐标中，前方为 +X，左方为 +Y，上方为 +Z；左右肌肉附着点及相机实际朝向已经核对。

| 视图 | 相机位于模型哪侧 | MuJoCo azimuth | 屏幕左右 |
| --- | --- | --- | --- |
| 前观 | +X | 180° | 模型右 / 模型左 |
| 后观 | −X | 0° | 模型左 / 模型右 |
| 左侧观 | +Y | 270° | 前 / 后 |
| 右侧观 | −Y | 90° | 后 / 前 |
| 左前斜观 | +X、+Y | 225° | 使用复合方向提示 |

所有相机保持 elevation=0、IPD=0，避免相机俯仰与双目视差干扰二维标注。五个视角使用相同状态和视频时间戳。

## 可见结构与投影示意

MP4 中实线由 MuJoCo 正常深度渲染，骨骼会遮挡深部路径。网页叠加的虚线则显示所选肌肉路径的二维投影，包含遮挡部分。名称引线指向该路径末端，**不是对临床附着点的独立标定**。

投影坐标通过 `ten_wrapadr / ten_wrapnum / wrap_xpos` 获取逐帧世界路径，再由实际 `MjvGLCamera` 的位置、方向与视锥投影。放大和平移对视频与标注使用相同变换。不得把这些线条当成真实肌腹边界。

## 教学解释的依据与尚未完成的校验

[National Academies / NCBI](https://www.ncbi.nlm.nih.gov/books/NBK557988/) 区分主要咀嚼肌与参与张口的辅助肌群；[StatPearls](https://www.ncbi.nlm.nih.gov/books/NBK541027/) 提供主要咀嚼肌的解剖背景。它们支持本界面的肌群组织方式，不证明模型的每个分束、附着点和边界条件都符合个体生理。

课程使用前仍应记录所用教材版本、页码、每个结构的核对结果和分歧。原始网格存在简化与缺失；界面不添加虚构骨骼、不将路径包装成完整医学标本。
